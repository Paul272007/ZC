# ZC

The package manager for C and C++!

## Dependencies and requirements

For the moment ZC is only available for Linux.

- Clang and LLVM
- Cmake >= 3.12 and Make
- Git

## Installation

Quick install : `bash -c "$(curl -fsSL https://raw.githubusercontent.com/Paul272007/ZC/refs/heads/stable/bootstrap.sh)"`

## Usage

`zc <command>`

Run `zc --help` or `zc <command> --help` for more information
