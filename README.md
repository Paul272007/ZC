# ZC

The package manager and build system for C and C++!

## Requirements

For the moment ZC is only available for Linux.

## Dependencies

- `clang` or `gcc`
- `make`
- `git`
- `pkg-config`

## Build dependencies

- `clang` and `llvm`
- `cmake`
- `libarchive`
- `libcurl`
- `openssl`
- `nlohmann-json`

## Installation

### Arch Linux

`yay -S zc-git` or `paru -S zc-git`

### Quick installation

```bash
curl -fsSL https://raw.githubusercontent.com/Paul272007/ZC/refs/heads/stable/bootstrap.sh | bash
```

## Usage

Run `zc --help` or `zc <subcommand> --help` for more information
