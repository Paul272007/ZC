# ZC

The package manager for C and C++!

## Dependencies and requirements

For the moment ZC is only available for Linux.

- Clang + LLVM
- Cmake

## Installation

Simply run `./install.sh` with root privileges from the repo root.
Then you can also uninstall it using `./uninstall.sh`

## Usage

`zc <command>`

Run `zc --help` or `zc <command> --help` for more information
